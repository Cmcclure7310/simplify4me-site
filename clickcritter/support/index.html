ClickCritter support

Quick fixes for the little things.

ClickCritter is designed to be simple and local. Most issues can be fixed with a refresh or by checking one setting in the popup.

↻

I just installed ClickCritter and nothing changed

Refresh the webpage once. Tabs that were already open before installation or an extension reload may need one refresh before ClickCritter can run there.

⛔

ClickCritter says it can't run on this page

Chrome intentionally blocks extensions on protected locations such as chrome:// pages, the Chrome Web Store, and some other browser-controlled pages. This is normal.

↖

My cursor looks normal

Open the ClickCritter popup and confirm the master switch is on. Then choose a cursor skin and size. Some browser-controlled interface areas always keep Chrome's normal cursor.

✦

Trails or click effects are missing

Check the Trail and Click effect options in Customize. If reduced motion is enabled — or your system prefers reduced motion — visual effects may be limited.

XP

XP or distance seems lower than expected

ClickCritter intentionally ignores tiny pointer jitter. Distance is an approximate fun statistic based on screen pixels, so it should not be treated as a physical measurement.

✓

How do I pause everything?

Turn off the master switch in the popup. The normal system cursor returns, trails and click animations stop, and activity tracking pauses. Your saved progress remains intact.

Still having trouble?

Try a clean extension refresh.

  1. Open chrome://extensions in Chrome.
  2. Find ClickCritter and make sure it is enabled.
  3. Return to the webpage where you want to use it and refresh that tab.
  4. Open the ClickCritter popup and confirm the master switch is on.

If the extension is installed from the Chrome Web Store, feedback and support can also be submitted through its store listing after publication.
