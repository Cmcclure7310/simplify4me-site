ClickCritter Privacy Policy

Version 2.0.0 · Updated October 10, 2026

ClickCritter customizes your cursor and visual effects on supported webpages. It does not require an account, include extension analytics or tracking pixels, operate a backend, make remote API requests, or load remote executable code.

Local information

ClickCritter stores settings, selected cursor/theme, appearance controls, favorite and recently applied theme IDs, saved custom themes, cropped cursor images, local rotation dates, schedules and user-created domain rules in chrome.storage.local in your Chrome profile. It does not use Chrome sync storage.

If you enable Fun Stats, mouse-click counts and estimated pointer movement distance are aggregated locally with XP and achievements. No pointer coordinates or event logs are saved. V1 progress and a local migration backup are retained. Fresh installs default to stats disabled; upgrading V1 users retain their existing stats feature unless they turn it off. Master disable pauses activity tracking and effects.

Photo files are decoded and cropped locally. The original photo file is not retained in extension storage; the saved theme contains small cropped PNG cursor images. Import/export is local. Exported files can contain your cropped images and theme preferences; sharing a file yourself shares those contents with its recipients.

Webpage access

The content script uses pointer events to render effects and optionally aggregate movement/counts. It reads the current page's hostname in memory solely to compare it with domain rules you explicitly created. That hostname is not added to a browsing-history log or transmitted. Cursor selectors affect normal elements and link/button states. Optional accents style scrollbars, selection highlighting and keyboard focus without changing page layout.

ClickCritter does not collect browsing history, page contents, page titles, typed text, passwords, cookies, account information or general URL logs. It does not upload cursor activity, domain rules, images or preferences. No information is sold or shared by the extension.

Permissions

storage saves the local information described above. alarms checks local rotation/schedules while Chrome runs; the alarm is used only when automatic rotation or schedules are configured. HTTP/HTTPS content-script access permits automatic cursor/effects behavior on ordinary webpages. Packaged cursor PNGs are exposed as web-accessible resources so the extension can display its artwork. No history, cookies or tabs permission is requested.

Your choices

Use the master switch for immediate disable. Disable optional Fun Stats, ambient effects, Page Accents or automatic rotation separately. Delete saved custom themes and site rules through their controls. Uninstalling the extension removes its local extension storage, including preserved V1 data and migration backup. Browser/OS backup behavior remains subject to your own device configuration.

The public website is hosted on GitHub Pages. GitHub's website-hosting practices and the Chrome Web Store's own account/install processing are separate from this extension's local operation. External homepage, privacy and support links open only when you choose them.
