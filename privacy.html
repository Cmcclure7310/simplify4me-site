PRIVACY POLICY

Private by design.

Effective September 10, 2026. This policy describes Simplify 4 Me 3.0, a Chrome extension that helps make webpages easier to read and understand.

The short version

Simplify 4 Me does not require an account and does not operate a cloud backend. The extension does not sell personal data, run behavioral advertising, or send your webpage text to Simplify 4 Me servers. Core reading analysis is performed by code packaged with the extension.

Website content

To provide its user-facing features, Simplify 4 Me can access readable text on webpages where the extension runs. This is necessary for features such as selected-text simplification, Key Points, Hard Words, Quick Read, Focus Mode, Complexity Lens, and optional site preferences.

That webpage text is processed locally by the extension for those features. Simplify 4 Me does not transmit the webpage text to a developer-operated server or third-party AI service.

Read Aloud

When you choose Listen or Read Aloud, the extension passes the selected readable text to the speech-synthesis capability provided by Chrome and your operating system. Simplify 4 Me itself does not send that text to a developer-operated speech server. Some voices or operating-system speech services may be implemented by the browser or OS provider; their handling is governed by that provider's settings and privacy terms.

Settings stored on your device

Simplify 4 Me stores preferences in Chrome's local extension storage. These can include your simplification strength, Quick Read display preferences, custom replacement rules, speech speed, feature toggles, and the hostnames of websites you explicitly choose for “Always help on this site.”

These settings are used only to provide and remember the extension experience. Version 3.0 does not include an analytics service or a developer-operated account-sync service.

Permissions

The extension requests storage to remember your local settings and contextMenus to offer user-invoked reading actions from Chrome's right-click menu. The extension's content script runs on normal HTTP and HTTPS webpages because selection assistance, Focus Mode, Complexity Lens, and Quick Read must work on the pages you choose to read.

Simplify 4 Me does not run on Chrome internal pages such as chrome://, the Chrome Web Store's protected pages, or other browser-restricted locations where Chrome blocks extensions.

Data collection, sale, and sharing

  • No developer-operated user account.
  • No behavioral analytics in version 3.0.
  • No sale of personal data.
  • No advertising profile.
  • No cloud AI or remote API used for simplification.
  • No remote JavaScript loaded by the extension.

Custom rules and exports

Custom rules you create remain in Chrome's local extension storage unless you export them. If you export settings, Chrome downloads a JSON file to a location you choose. If you import settings, the extension reads that file only to restore supported Simplify 4 Me preferences.

Changes to this policy

If a future version materially changes how information is processed, this policy will be updated before or alongside that release. A future feature that sends data to a server would require an updated disclosure and would not be silently added under this version's privacy promises.

Support

For help with Simplify 4 Me, visit the support page. You can also use the support contact shown on the Chrome Web Store listing.

Simplify 4 Me is a reading aid, not a substitute for the original source. For legal, medical, financial, safety-critical, or other high-stakes material, review the original wording and consult an appropriate qualified source when needed.
