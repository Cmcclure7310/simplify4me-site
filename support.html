SUPPORT

Get back to reading.

Simplify 4 Me is designed to be simple enough that you should not need a manual. These are the answers to the things most likely to come up.

How do I simplify something?

Highlight readable text on a normal webpage. A small Simplify button appears beside the selection. Choose it to open the result card. You can also right-click selected text and choose “Simplify selected text,” or use the extension popup.

What are Light, Clear, and Simple?

Light makes smaller wording changes. Clear is the balanced default for everyday language. Simple makes stronger replacements and simplifies more phrases. The tool is deterministic, so it does not invent a new explanation or add facts that were not in the source.

What is Quick Read?

Quick Read finds the main readable text on many article-style webpages and displays it in a calm reading view. You can switch between the original wording, a simpler version, and extracted key points, then change theme and text size or listen aloud.

Why does Quick Read say there is not enough article text?

Some pages are apps, dashboards, stores, image galleries, or heavily scripted layouts rather than normal articles. Simplify 4 Me intentionally fails safely instead of guessing when it cannot find enough readable content.

What does Complexity Lens do?

It underlines difficult words from Simplify 4 Me's built-in local dictionary. It does not send the page away for analysis. On supported Chrome versions it uses the browser's Custom Highlight API, which avoids wrapping or rewriting the webpage's text.

How does Focus Mode work?

Move your pointer over readable blocks such as paragraphs and list items. Focus Mode highlights that block and dims the area around it. Turn it off from the popup or the keyboard shortcut when you are done.

Can I change a webpage permanently?

No. “Replace” only changes a simple selected text node in your current local page session, and it offers a short undo window. Reloading the webpage restores the website's original content. Complex multi-element selections are never replaced.

Does Simplify 4 Me use ChatGPT or another AI service?

No. Version 3.0 uses a packaged local rules engine for simplification, extractive key points, and hard-word help. There is no cloud AI account, API key, or downloaded language model.

Does it collect what I read?

Version 3.0 has no behavioral analytics service and does not send webpage text to a Simplify 4 Me server. See the privacy policy for details, including how Read Aloud uses the speech feature supplied by Chrome or your operating system.

Why does it not work on a Chrome page or the Chrome Web Store?

Chrome blocks extensions from injecting content scripts into protected browser pages and some protected web properties. Open a normal HTTP or HTTPS webpage and try again.

I just updated and the popup says to refresh the page.

A tab that was already open before the extension updated may still be running the old content script. Refresh that webpage once. Newly opened pages should use the new version automatically.

How do I add my own word replacement?

Open the extension settings, find “My Rules,” enter the complicated word or phrase and the simpler replacement, then choose Add. Your custom rules run before the built-in replacements and are stored locally in Chrome.

Can I back up my settings?

Yes. Settings includes Export and Import. Export creates a JSON file containing supported Simplify 4 Me preferences and custom rules. Import restores a compatible JSON settings file.

Keyboard shortcuts

  • Alt + Shift + S: Simplify the current selection.
  • Alt + Shift + R: Open Quick Read.
  • Alt + Shift + F: Toggle Focus Mode.

Chrome may change or reserve shortcuts depending on your system. You can manage extension shortcuts from Chrome's extension shortcut settings.

Before reporting a problem

  1. Refresh the webpage once.
  2. Confirm it is a normal http:// or https:// page.
  3. Try a short selection inside one paragraph.
  4. If Quick Read is the problem, try it on a normal news or article page.
  5. Open Simplify 4 Me settings and confirm the selection bubble is enabled if you expect it to appear automatically.

If the issue remains, use the support contact available on the Simplify 4 Me Chrome Web Store listing and include the Chrome version, webpage address, and a short description of what happened. Do not send sensitive text from the webpage.
