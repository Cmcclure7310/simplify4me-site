# Simplify 4 Me 3.0 — Chrome Web Store listing

## Product name
**Simplify 4 Me — Reading Assistant**

## Recommended category

## Short description
**Make difficult webpages easier to read with instant simplification, Quick Read, focus tools, and private on-device processing.**

## Detailed description
Hard text should not stop you in your tracks.

Simplify 4 Me is a private reading assistant for Chrome that helps make difficult webpages easier to read and understand. Highlight confusing text and get a clearer version beside the page — without creating an account, writing a prompt, connecting an API key, or downloading an AI model.

### HIGHLIGHT → SIMPLIFY → UNDERSTAND
Select readable text on a webpage and choose Simplify. A focused result card gives you three useful views:

• **Simpler** — rewrites known difficult wording into plainer language.
• **Key Points** — pulls out important sentences from longer text without inventing new facts.
• **Hard Words** — identifies supported difficult words and shows simpler alternatives and meanings.

Choose how much help you want with three strengths: **Light**, **Clear**, or **Simple**.

### QUICK READ
Turn many article-style webpages into a calm reading view with:

• Original or simplified wording
• Extracted key points
• Adjustable text size
• Adjustable reading width
• Comfortable line spacing
• Light, warm, and midnight themes
• Focus mode
• Read Aloud

### FOCUS MODE
Keep your eyes on one block at a time. Focus Mode emphasizes the paragraph or readable block under your pointer and dims surrounding content.

### COMPLEXITY LENS
Underline difficult words that Simplify 4 Me's local dictionary knows how to explain. It uses Chrome's highlighting support rather than wrapping or rewriting page text.

### READ ALOUD
Listen to selected text or Quick Read content using speech synthesis supplied by Chrome and your operating system. Voice availability can vary by device.

### YOUR RULES, YOUR WAY
Add custom word or phrase replacements for language you see often. Export or import your Simplify 4 Me settings as JSON when you want a backup.

### PRIVATE BY DESIGN
Simplify 4 Me 3.0 has:

• No required account
• No API key
• No developer cloud backend
• No cloud AI service for simplification
• No externally downloaded AI model
• No remote JavaScript
• No behavioral analytics service
• No advertising profile

Core simplification, key-point extraction, hard-word help, Focus Mode, Complexity Lens, and Quick Read extraction run from code packaged with the extension. Settings and custom rules are stored locally in Chrome.

Read Aloud passes the text you choose to the speech-synthesis capability supplied by Chrome or your operating system. Simplify 4 Me itself does not send text to a developer-operated speech server.

### SAFE BY DEFAULT
Simplify 4 Me avoids forms, code blocks, editable fields, scripts, and other unsafe elements when offering on-page simplification. Replace is limited to a simple selection inside one text node and offers a short undo window. Reloading the webpage restores the website's original text.

Keyboard shortcuts:
• Alt + Shift + S — Simplify selection
• Alt + Shift + R — Quick Read
• Alt + Shift + F — Focus Mode

Simplify 4 Me is a reading aid. For legal, medical, financial, safety-critical, or other high-stakes material, always review the original source.
