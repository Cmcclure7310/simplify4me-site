# Simplify 4 Me 3.0

Simplify 4 Me is a Manifest V3 Chrome reading assistant whose single purpose is making normal webpages easier to read and understand.

## Core features
- Highlight-to-Simplify floating control.
- Simpler, Key Points, and Hard Words result views.
- Light / Clear / Simple deterministic local simplification strengths.
- Quick Read text-first reader mode.
- Read Aloud through browser/OS speech synthesis.
- Focus Mode.
- Complexity Lens via the CSS Custom Highlight API where available.
- Custom local word/phrase rules.
- Optional per-site preference.
- Settings export/import.
- Keyboard shortcuts and context-menu commands.

## Privacy architecture
The extension package contains all code used for its core reading analysis. It has no developer cloud backend, no remote JavaScript, no cloud AI call, no API key, no externally downloaded AI model, and no behavioral analytics service.

Website text is handled locally for user-facing reading features. If the user enables “Always help on this site,” the hostname is stored in Chrome local extension storage. Read Aloud delegates selected text to the speech-synthesis capability supplied by Chrome or the operating system; available voices and their implementation depend on that platform.

## Safety behavior
- The selection helper ignores inputs, textareas, selects, buttons, editable regions, `pre`, `code`, scripts, styles, SVG, canvas, and iframes.
- Replace is enabled only when the current selection starts and ends in the same non-editable text node.
- Replace is session-only page DOM modification and provides an undo window.
- Quick Read builds its own elements from text strings and never imports source HTML into its interface.
- Complexity Lens uses `Range` objects with the browser Highlight API rather than injecting wrappers into page text.
- UI is isolated in Shadow DOM to reduce collisions with page styles.

## Keyboard shortcuts
- `Alt+Shift+S` — Simplify selection
- `Alt+Shift+R` — Quick Read
- `Alt+Shift+F` — Focus Mode

## Build
The release workspace includes automated unit, browser, static-security, packaging, and artwork-dimension checks. The Chrome Web Store upload ZIP is generated by the GitHub Actions release workflow so `manifest.json` is at the archive root.
