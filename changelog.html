What's new.

Simplify 4 Me 3.0 is a major rebuild focused on making difficult webpages easier to read and understand without adding cloud accounts or remote AI.

VERSION 3.0.0 — SEPTEMBER 2026

A complete reading-assistant update

  • New highlight-to-Simplify experience with an in-page result card.
  • Three simplification strengths: Light, Clear, and Simple.
  • New Key Points view using extractive local sentence scoring.
  • New Hard Words view with plain-English alternatives and meanings.
  • New Quick Read distraction-free article view.
  • Quick Read themes, text size controls, line spacing, reading width, key points, and simplified view.
  • Read Aloud for selected text and Quick Read content using browser/OS speech synthesis.
  • Focus Mode to emphasize the reading block under your pointer.
  • Complexity Lens to underline known difficult words without rewriting page text.
  • “Always help on this site” preference for sites where you want the Complexity Lens automatically.
  • Safer Replace behavior limited to a single text node, with a short undo window.
  • New custom-rules manager with settings import and export.
  • New keyboard shortcuts and right-click actions.
  • Completely redesigned popup, settings page, and interactive first-run onboarding.
  • Settings migration logic for common Simplify 4 Me 2.x preference formats.
  • Privacy-focused architecture with no developer cloud backend, no API key, no remote code, and no behavioral analytics.

What stayed the same

The original idea is still intact: make difficult wording easier. Version 3.0 expands that idea into a more complete reading workflow while keeping the extension independent and fast.
